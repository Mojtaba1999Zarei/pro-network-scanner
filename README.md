# 🚀 Mojtaba's Pro Network Scanner (v2.0)

A high-performance, multi-threaded network reconnaissance tool written in Python. This tool is designed for security enthusiasts and system administrators to perform fast port scanning and service identification (Banner Grabbing).

## ✨ Features
- **Multi-threaded Scanning:** Extremely fast port discovery.
- **Advanced Banner Grabbing:** Identifies services like HTTP (LiteSpeed, Apache, Nginx), FTP (ProFTPD), and Mail Servers.
- **Smart Requests:** Mimics real browser headers to bypass basic security filters.
- **Beautiful UI:** Uses `Rich` library for clean, organized tables and colored output.

## 🛠 Installation

1. Clone the repository:
      bash
   git clone https://github.com/Mojtaba1999Zarei/pro-network-scanner.git

Run the script and follow the interactive prompts:
python scanner.py
